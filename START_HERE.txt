QUICK START (5 MINUT)
================================================================================

1. CONFIGURE WiFi:
   Edit: include/wifi_config.h
   
   SSID = "your-network"
   PASSWORD = "your-password"
   ENABLE_WIFI_ON_BOOT = true

2. BUILD:
   platformio run -e esp32-s3-devkitc1-n4r8-usb

3. UPLOAD:
   platformio run --target upload -e esp32-s3-devkitc1-n4r8-usb

4. MONITOR:
   platformio device monitor -b 115200 -p COM8

5. TEST:
   curl http://192.168.1.100/api/status
   WebSocket: ws://192.168.1.100:81/ws/ui-events

REST API ENDPOINTS
================================================================================

GET /                               Status page
GET /api/status                     System metrics (uptime, memory, temp)
GET /api/screen                     Current screen info
GET /api/config                     Device configuration
GET /api/brightness                 Get brightness level

POST /api/brightness                Set brightness {"level": 0-100}
POST /api/config                    Update configuration

WebSocket Channels:
  ws://device:81/ws/ui-events      LVGL UI events (screen changes, clicks)
  ws://device:81/ws/sensors        Sensor data (CPU temp, custom sensors)

================================================================================
TROUBLESHOOTING QUICK TIPS
================================================================================

WiFi Won't Connect:
  1. Check SSID/PASSWORD in wifi_config.h
  2. Verify router is 2.4GHz (ESP32-S3 limitation)
  3. Check Serial Monitor for error messages

HTTP Endpoints Timeout:
  1. Ping device: ping 192.168.1.100
  2. Check firewall blocking ports 80/81
  3. Verify IP address from Serial Monitor

WebSocket Disconnects:
  1. Implement client-side reconnect logic
  2. Monitor PSRAM in Serial output
  3. Check task stack sizes

Out of Memory:
  1. Monitor "Free Heap" in Serial Monitor
  2. Reduce buffer sizes if needed
  3. Profile task memory usage

DEVELOPMENT WORKFLOW
================================================================================

Adding a New API Endpoint:

1. Edit: src/integration/web_integration.cpp
2. Add route in WebIntegration::start():

   Routes().get("/api/my-endpoint", [](Request& req) {
       JsonDocument doc;
       doc["status"] = "success";
       return Response::json(doc);
   });

3. Test: curl http://device/api/my-endpoint
4. Document in: docs/WEB_INTEGRATION.md

Publishing Real-Time Events:

1. Include: #include <web_integration.h>
2. Publish from any task/callback:
   
   WebIntegration::getInstance().publishSensorData(
       "sensor_name", 
       value, 
       "unit"
   );

3. Client receives via WebSocket automatically
